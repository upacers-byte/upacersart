UPACERS ART — "EXPLORE NATURE" PHOTO LIBRARY
=============================================

This folder organizes your nature photography by category.
Each subfolder matches a category TAB on your website's gallery.

SUBFOLDERS  (folder name  →  category shown on site)
---------------------------------------------------
  bugs/                  →  Bugs
  flies/                 →  Flies
  ants/                  →  Ants
  people-and-lifestyle/  →  People & Lifestyle
  snails/                →  Snails
  spiders/               →  Spiders
  worms/                 →  Worms
  flowers/               →  Flowers
  animals/               →  Animals
  birds/                 →  Birds


HOW TO USE THESE FOLDERS
------------------------
Option A — Upload through the website (easiest):
  1. Put your photos into the matching folder here (e.g. spiders/spider-01.jpg)
  2. Open your website and click the gear button ⚙️ (bottom-right)
  3. Go to the "Photos" tab → "Add Photo" → "Upload Photo"
  4. Pick the photo from this folder, then choose the matching category

Option B — Reference by path (advanced):
  If you place a photo at  spiders/spider-01.jpg  you can use the path
  /explore-nature/spiders/spider-01.jpg  as the image URL.


TIPS
----
• Use simple filenames with NO spaces (e.g. ant-closeup.jpg, not "my ant.jpg")
• JPEG (.jpg) photos work best for the web
• You can keep your full-resolution originals here safely — the website
  only uses a compressed web copy, and your originals never get exposed.
